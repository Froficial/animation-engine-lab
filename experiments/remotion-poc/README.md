# Experimento Remotion

Execute `npm ci`, `npm run dev` para prévia ou `npm run render` para RigProof. Composição alternativa: SkeletonProof.

As duas composições usam 450 frames, 30 fps, 540×960. O workflow ../../.github/workflows/render-proof.yml gera MP4s, PNGs e metadados. Consulte o README da raiz para limites e instruções.
